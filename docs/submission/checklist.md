# Devpost submission checklist

From the official rules (<https://paypalaihackathon.devpost.com/rules>) and the Devpost help center,
checked 2026-10-23. Details and sources are in [ENV.md](../ENV.md) section 5. Internal deadline:
11 Nov 2026 18:00 NPT. Official close: 12 Nov 2026 12:00 pm PT.

## Required

- [ ] Text description of features and functionality, in English
- [ ] Functional demo: complete setup and run instructions in the repository, and a hosted demo URL
      with sandbox test logins in the testing instructions
- [ ] Public repository (GitHub, GitLab or Bitbucket) with all source, assets and instructions
- [ ] Open source licence detected and visible in the repository About section
- [ ] Demo video under 3 minutes, public on YouTube, showing the project working, with no third
      party trademarks or copyrighted music; link on the form
- [ ] The AI tools used and how they were used (overview, "Tools")
- [ ] Project free to use for testing until 15 Dec 2026 8:00 am PT (hosted demo and database kept alive)
- [ ] Built-with tags (25 maximum), project name, tagline, project story
- [ ] Thumbnail (JPG, PNG or GIF, 5 MB maximum, 3:2 recommended)

## Optional

- [ ] Image gallery screenshots
- [ ] File upload (35 MB maximum; zip, pdf, word or apk)
- [ ] Try-it-out links (hosted demo, repository)

## Check manually (the live form was not visible)

- [ ] Join the hackathon, start a project, and read every field on "Enter a Submission"
- [ ] Note any hackathon-specific questions (the help center's "additional details" step)
- [ ] Note the tagline and story length limits and the image gallery limits (not stated publicly)
- [ ] Confirm YouTube is the only accepted video host for this hackathon (rules say YouTube)
- [ ] Confirm whether the form asks for the Render or AG Grid tools by name
- [ ] Save a draft early and re-open it to confirm it persists

## Rules to keep in mind

- One Grand Prize or one Honorable Mention, plus one Sponsor Prize, per project
- Tie break: the highest score on the first criterion, then the next in order
- After the deadline nothing can be edited (rules section 5)
